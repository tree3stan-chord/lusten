# lusten
(noun) : jam with chat

## what is this?

A shared listening experience web app that allows users to create and join music rooms for synchronized listening.

## Getting Started

### Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

### Production Build

```bash
npm run build
npm start
```

### Environment Configuration

Copy `.env.local.example` to `.env.local` and configure your environment variables.

## Tech Stack

- **Frontend**: Next.js 15 with TypeScript
- **Styling**: Tailwind CSS 4.0
- **Deployment**: Node.js compatible servers with nginx proxy
